# ▶️ How to Use

## Power BI

Open any Power BI project folder and launch the available `.pbix` file using **Power BI Desktop**.

You can also explore the Power BI Project (`.pbip`) structure to understand the underlying report and semantic-model files.

## Tableau

Open the `boxoffice` folder and launch either the `.twb` workbook or `.twbx` packaged workbook with **Tableau Desktop**.

## Python

Open the `trends` folder and launch:

```text
trends1.ipynb
```

using **Jupyter Notebook**, **JupyterLab**, or **VS Code**.
