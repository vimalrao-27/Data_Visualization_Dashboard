## ▶️ How to Explore the Projects

### Power BI

1. Open the required project folder.
2. Download the `.pbix` file or Power BI Project files.
3. Open the project using **Microsoft Power BI Desktop**.
4. Review the dashboard, filters, visuals, and data model.

### Tableau

1. Open the [Box Office](./boxoffice) folder.
2. Download the `.twb` or `.twbx` file.
3. Open it using **Tableau Desktop**.
4. Explore the worksheets and dashboards.

### Python

1. Open the [Trends](./trends) folder.
2. Open the Jupyter Notebook using **Jupyter Notebook** or **JupyterLab**.
3. Run the cells to reproduce the analysis and visualizations.
